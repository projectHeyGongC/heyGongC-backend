# heyGongC
헤이공씨 CCTP App 프로젝트

> 2023.12 ~ 2024.06 / Server 3, Android 2, iOS 2

## Tech Stack
- Backend
  - Java, Spring Boot, JPA, JWT, Swagger
- DB
  - PostgreSQL
- DevOps / Infra
  - AWS EC2, Docker, GitHub Actions, Nginx
